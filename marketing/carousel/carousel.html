QueryBuilder HubSheet 11 / 14

Viewers get dashboards. Only dashboards.

A Viewer's whole reach on the server is eight endpoints, and nothing else answers:

  1. 1 · the dashboard list
  2. 5 · a query's options, via a dashboard
  3. 2 · one dashboard
  4. 6 · a chart render, via a dashboard
  5. 3 · a tile's chart
  6. 7 · a chart's data download
  7. 4 · dashboard parameter options
  8. 8 · their own profile

No query list, no builder, no SQL. Each chart is drawn with the Viewer's own scope.
